# Excalidraw Tauri Roadmap

Este proyecto es una aproximación inicial y experimentación con herramientas modernas como [Astro](https://astro.build/), TailwindCSS y Chart.js. Su propósito es didáctico, permitiendo aprender sobre la integración de tecnologías frontend para construir aplicaciones dinámicas y eficientes.

## Tecnologías Usadas

- **Astro**: Framework para generar contenido estático y dinámico de alta velocidad.
- **TailwindCSS**: Framework CSS para un estilado eficiente y moderno.
- **Chart.js**: Biblioteca para la creación de gráficos interactivos y personalizables.

## Scripts Esenciales

- `dev`: Levantar servidor de desarrollo.
- `build`: Construir la aplicación para producción.
- `preview`: Vista previa de la aplicación en producción.
