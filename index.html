Tauri Excalidraw Blueprint

Análisis de Esfuerzo por Componente

Distribución técnica basada en la complejidad de los algoritmos y la integración con el sistema nativo.

01

Arquitectura de Núcleo (Tauri/Rust)

Configuración del entorno de ejecución híbrido. El objetivo es establecer un puente de comunicación seguro y eficiente entre el proceso de renderizado (Frontend) y el proceso principal (Rust).

Paso 1.1: Inicialización del Toolchain

Configurar Rust mediante rustup e instalar las dependencias de compilación específicas de tu OS (C++ build tools en Windows, dependencias de WebKit en Linux). Crear el scaffold inicial con npm create tauri-app seleccionando React + TypeScript.

Paso 1.2: Definición de Comandos y Estado en Rust

Implementar tauri::command en main.rs para operaciones que requieren privilegios de sistema. Definir una estructura de estado compartida en Rust usando Managed State para gestionar metadatos de la aplicación de forma global.

02

Motor de Renderizado Imperativo

Abandono del DOM tradicional para el dibujo. Implementación de una capa de renderizado basada en la Canvas API que permita el estilo "hand-drawn".

Paso 2.1: Integración de Rough.js

Configurar el generador de Rough.js dentro de un useLayoutEffect. Aprender a mapear formas geométricas puras (líneas, elipses) a "drawables" que conserven el estilo imperfecto. Optimizar la regeneración para evitar parpadeos.

Paso 2.2: Gestión del Frame Loop

Crear una función de renderizado que limpie el canvas y re-dibuje todos los elementos del estado en cada actualización. Implementar un sistema de coordenadas global para manejar el zoom y el paneo del lienzo.

03

Lógica de Geometría y Estado

El cerebro de la aplicación. Manejo de interacciones complejas, selección de objetos y persistencia del historial de acciones.

Paso 3.1: Algoritmos de Hit Detection

Implementar lógica matemática para detectar si un cursor está dentro de una forma. Para líneas, usar cálculo de distancia punto-segmento. Para formas cerradas, implementar el algoritmo de ray-casting o bounding box checks.

Paso 3.2: Sistema Undo/Redo y Serialización

Utilizar una estructura de datos tipo Stack o una librería como zustand-middleware-immer para gestionar el historial de estados. Asegurar que cada objeto sea serializable a JSON para su posterior almacenamiento vía Rust.

04

Persistencia y Binarios

Finalización del producto nativo. Acceso a archivos y empaquetado para distribución.

Paso 4.1: I/O de Archivos Nativos

Configurar los permisos de fs en el archivo tauri.conf.json. Implementar diálogos nativos de "Guardar" y "Cargar" que pasen el stream de datos a Rust para su escritura en disco duro.

Paso 4.2: Optimización de Build

Configurar el compilador de Rust para el modo release. Aprender a usar strip para reducir el tamaño del binario y configurar los iconos y metadatos del instalador (.msi o .deb).
